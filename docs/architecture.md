# Архитектура MVP `parsedwg`

## Что реализовано

- веб-интерфейс на `FastAPI`;
- загрузка `DWG` / `DXF` и пояснительной записки;
- извлечение текстовых позиций из чертежа и сопроводительного документа;
- нормализация строк в единый набор позиций;
- генерация Excel-книги с листами `СО`, `ВОР`, `Смета`, `Сводка`.

## Поток обработки

1. Пользователь загружает чертёж и при необходимости записку.
2. Для `DWG` используется внешний конвертер `ODAFileConverter` (если он установлен).
3. `DXF` читается библиотекой `ezdxf`, текст и атрибуты блоков извлекаются в сырой список строк.
4. Каждая строка прогоняется через набор регулярных выражений и классифицируется как:
   - `equipment`;
   - `materials`;
   - `works`.
5. Дубликаты агрегируются по наименованию, единице измерения и разделу.
6. Итог сохраняется в Excel-файл.

## Ограничения

- прямой парсинг бинарного `DWG` без внешнего конвертера не выполняется;
- смета формируется как заготовка с колонкой цены и формулой `количество × цена`;
- качество результата зависит от того, насколько стандартизированы подписи на чертеже.
