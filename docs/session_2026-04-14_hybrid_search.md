## Параметры гибридного поиска

```python
async def hybrid_search(
    query: str,
    entity_type: str | None = None,
    top_k: int = 5,
    alpha: float = 0.5,  # 0.5 = 50% BM25 + 50% Vector
) -> list[dict]:
```

**alpha** — вес BM25 (0..1):
- `alpha=0.7` → 70% BM25 + 30% Vector (если текст важнее)
- `alpha=0.5` → 50/50 (сбалансированный поиск)
- `alpha=0.3` → 30% BM25 + 70% Vector (если семантика важнее)

## Пример использования

```python
from parsedwg.rag import hybrid_search

# Гибридный поиск
results = await hybrid_search(
    "насос на 3-м этаже водоснабжения",
    entity_type="block",
    top_k=10,
    alpha=0.5
)

#   ...
# }
```

## Преимущества гибридного поиска

| Метод | Сильные стороны | Слабые стороны |
|-------|-----------------|----------------|
| **BM25** | Точные термины, операторы (AND, OR) | Не понимает синонимы |
| **Vector** | Семантика, синонимы | Может быть неточен для специальных терминов |
| **Гибридный** | Лучшее из двух миров | Требует настройки alpha |
