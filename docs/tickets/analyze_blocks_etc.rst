==============================
Задача по классификации блоков
==============================

1. Блоки (**INSERT**) — готовые семантические единицы

	Проектировщик рисует розетку один раз как блок SOCKET_220V и вставляет 50 раз. Это уже готово: 50
	INSERT'ов одного блока = 50 розеток. Не нужно группировать примитивы — работа уже сделана.

	Если у блока есть атрибуты (**ATTRIB**) — там прямо название, марка, мощность. Это главный канал для СО.

	Задача: посчитать количество INSERT по каждому блоку + извлечь атрибуты. Всё.

2. Слои — семантика по принадлежности

	Слой Насосы-Циркуляционные заранее говорит: всё на нём — циркуляционные насосы. Один раз
	классифицируешь 235 слоёв (вручную или через LLM), дальше любой примитив автоматически получает
	тип.

3. Текст + пространственная близость

	Текст Н-1 рядом с кружком = это насос №1. Текст с номером позиции рядом с объектом — тот же
	принцип, что на бумажном чертеже: подпись "прилеплена" к объекту геометрически.

	Здесь нужна геометрическая свёртка: для каждого TEXT/MTEXT найти ближайший не-текстовый примитив.
	Координаты у нас уже есть (location).

Что это даёт на практике:

* Что извлекается 
* Сколько покрывает 
* Что нужно доработать

* INSERT по блокам + атрибуты 60-80% типового чертежа. Сохранять INSERT.block_name и ATTRIB
* Классификация по слою Оставшиеся + обогащение 
* Справочник layer → категория
* Текст → объект по близости 
* Нестандартизованные подписи 
* Пространственный индекс
* LLM — только на остаток (нераспознанные кейсы), не на весь чертёж. Дёшево и предсказуемо.
