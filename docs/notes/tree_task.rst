"Дерево" для документации (чертежей)
====================================

Весь представленный в качестве пример набор файлов рассматривается как "дерево", которое 
содержит несколько уровней:

* Каталоги, название первого уровня которых определяет соответствующую подсистему.
  Примеры:

  - "0005_22-Р-АИИСКУЭ3 Автоматизированные системы учета электроэнергии"
  - "0005_22-Р-АОВ3 Автоматизация отопления, вентиляции и кондиционирования"
  - "0005_22-Р-АППЗ3  Автоматическая противопожарная защита"
  - "0005_22-Р-АПС3 Автоматическая пожарная сигнализация"
  - "0005_22-Р-АСУВТ3 Автоматизированная система учета водо-, тепло-, холодо"
  - "0005_22-Р-АСУД3 Автоматизированная система управления систем здания"
  - "0005_22-Р-АУПТ3 Системы внутреннего и автоматического водяного пожаротушения"
  - "0005_22-Р-АХС3 Автоматизация системы холодоснабжения"
  - "0005_22-Р-БТС3 Беспроводные телекоммуникационные системы"
  - "0005_22-Р-В3 Система внутреннего водоснабжения"
  - "0005_22-Р-К3 Система внутреннего водоотведения"
  - "0005_22-Р-ОВ3.1 Системы отопления и теплоснабжения"
  - "0005_22-Р-ОВ3.2 Системы общеобменной вентиляции"

.. note:: 
    
  В каталогах есть подкаталоги 'Изм N', которые содержат файлы с изменениями. Они обычно в названии
  содержат дату изменения.
