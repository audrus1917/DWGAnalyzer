ezdxf
=====

Отдельные пункты описания с `сайта проекта http://ezdxf.mozman.at/`_:

* :mod:`ezdxf` это пакет для создания DXF-документов на Python и для чтения/изменения/записи существующих 
  DXF-документов;
* поддерживает множество версий DXF, но часть из них в режиме ``read-only``;
* поддерживает как ASCII, так и бинарные DXF-файлы;
* для чтения DWG-файлов требуется конвертация в DXF через сторонний инструмент, 
  например, `ODA File Converter https://www.opendesign.com/`_
* есть расширения, из которых отмечу :mod:`iterdxf` для итеративной обработки больших DXF-файлов;
* может обрабатывать упакованные zip'ом DXF-файлы, но с некоторыми ограничениями.

ODA File Converter
==================

`ODA File Converter https://www.opendesign.com/`_ — это бесплатный инструмент от `Open Design Alliance` для 
конвертации `DWG` в `DXF` и обратно. Он поддерживает широкий набор версий DWG и DXF.
